# 맞수 (Maetsu)

오목(렌주룰)·체스·장기 1:1 온라인 대국실. 서버 없이 브라우저끼리 직접 연결(WebRTC, PeerJS 신호 서버)합니다.

- 사용: 한 사람이 "방 만들기" → 5자리 코드 전달 → 상대가 "방 입장"에 코드 입력.
- 대국 중에는 두 사람이 모두 페이지를 열어 두어야 합니다.
- 오목: 흑은 정확히 5목만 승, 3·3 / 4·4 / 장목 금수. 체스: 캐슬링·앙파상·프로모션·3회 동형·50수·기물 부족 판정.
- 장기: 초(선)·한, 첫 수 전 상·마 배치 선택, 한 수 쉬기, 빅장을 풀지 않으면 무승부, 양쪽 연속 쉬면 무승부, 3회 동형 무승부.
- 채팅: 빠른 문구 + 자유 입력.
